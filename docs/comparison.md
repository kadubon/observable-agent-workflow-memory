# Comparison

This project is not a replacement for general agent frameworks.

- Letta/MemGPT: strong memory-management architecture; this project focuses on
  verified workflow promotion.
- LangGraph/LangMem: strong persistence and graph orchestration; this project
  is a framework-neutral memory verification kernel.
- Mem0/Zep/LlamaIndex/CrewAI memory: strong recall and persistence; this project
  prioritizes verification state, replayability, and fail-closed admissibility.
- Reflexion/Voyager/Generative Agents: strong reflection and skill generation;
  this project treats reflections and skills as candidates until receipts pass.
