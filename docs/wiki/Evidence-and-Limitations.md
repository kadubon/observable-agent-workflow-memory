# OAWM evidence and limitations

Observable Agent Workflow Memory (OAWM) 0.2.0b0 is Beta. Base schema 1.1 and the
opt-in receiver profile establish different bounded mechanisms. Documentation
inspection on September 25, 2026 does not create a new release qualification.

## Implemented mechanisms

The source implements version-bound evidence manifests, append-only receipts,
explicit promotion, strict action checks and receiver-profile lifecycle feedback.
[Source contracts](https://github.com/kadubon/observable-agent-workflow-memory/blob/af9da7e396d8694ce3c8d1affce27cfd7a5fcfdb/src/observable_agent_workflow_memory/qualified/wire.py),
[security assumptions](https://github.com/kadubon/observable-agent-workflow-memory/blob/af9da7e396d8694ce3c8d1affce27cfd7a5fcfdb/docs/security_model.md) and
[lifecycle rules](https://github.com/kadubon/observable-agent-workflow-memory/blob/af9da7e396d8694ce3c8d1affce27cfd7a5fcfdb/docs/memory-use-and-lifecycle.md) delimit what these mechanisms mean.
Generated is not verified; verified is not promoted; certified is not receiver-qualified.

## Historical tests and installed-artifact checks

The [0.2.0b0 publication record](https://github.com/kadubon/observable-agent-workflow-memory/blob/af9da7e396d8694ce3c8d1affce27cfd7a5fcfdb/docs/publication-0.2.0b0.md) records the September 21,
2026 release, exact source revision, historical tests and public artifact installation
checks. Its linked machine-readable evidence and release manifests preserve original
dates, hashes and version pairs. Those checks were not rerun for this guide.
Historical documentation saying no Wiki existed describes that earlier publication;
the present guide's separate Wiki publication does not rewrite that history.

## Synthetic and finite demonstrations

The registered normalize-lines primitive, receiver examples, scoped negative/refresh
path and finite economic comparisons have bounded inputs and declared costs.
Copied artifacts do not establish new capability. Finite model results do not
measure deployment gain; historical success does not establish current eligibility.
Passing tests do not prove universal correctness, safety or transfer.

## Source-inspected compatibility

This update checks names, command arguments and descriptions against source.
It does not execute examples or install optional companions. Historical native
interoperability is limited to the pinned ALT 0.5.0 and CCR 1.8.0 scope documented
in [native contracts](https://github.com/kadubon/observable-agent-workflow-memory/blob/af9da7e396d8694ce3c8d1affce27cfd7a5fcfdb/docs/alt-interoperability.md). VEK/CAIT are partial sidecars;
conceptual relationships and externally owned compositions are not new OAWM tests.

## External empirical results and unsupported claims

No external empirical AI acceleration experiment is reported. This documentation
establishes no performance gain, compute saving, general agent improvement,
autonomous intelligence growth, universal hallucination prevention or production
readiness. No AGI/ASI capability conclusion follows from it.

## Observable-only does not mean no trusted base

Trusted local storage, host clocks, configured checkers, permissions and execution
boundaries still matter. Receipt integrity is not source authentication;
deterministic replay is not external truth. Retrieval is not use, context exposure
is not checked service, and qualification is not authorization. Timeout is not a
checked negative. Domain-specific semantic checking is supported; generic schema
and digest checks are insufficient for semantic claims. See [checker guidance](https://github.com/kadubon/observable-agent-workflow-memory/blob/af9da7e396d8694ce3c8d1affce27cfd7a5fcfdb/docs/semantic_checkers.md).

## Availability is not indexing or adoption

README and ordinary docs retain meaningful entry points. GitHub documents
[Wiki indexing restrictions](https://docs.github.com/en/communities/documenting-your-project-with-wikis/about-wikis):
search-engine indexing requires at least 500 stars and disabled public editing.
Public availability, indexing, AI retrieval and adoption are distinct; publication
alone establishes none of the latter three.
