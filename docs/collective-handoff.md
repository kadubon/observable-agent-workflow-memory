# Bounded collective handoff

`oawm qualified export qualification.json` produces a real CCR 1.8.0 task-shaped
proposal, validated by that release's native parser. It is open and unleased,
read-only/dry-run constrained, with no executable commands or automatic PIC dispatch.
The immutable qualification digest, exact revision/context, completion criteria,
costs, dependencies and original source bytes accompany an OAWM-owned sidecar.
The current local invalidation snapshot remains a required host recheck.

`host_admission_required` is always true. Native task parsing does not mean CCR
enforces the new OAWM sidecar. Export never grants a lease, approval, reward, settlement
or execution authority and never writes CCR state. Host registration is explicit.
No imported manifest installs plugins, loads classes, fetches source references or
executes memory text. Companion runtime imports are fixed code paths chosen by OAWM.

VEK and CAIT outputs are deliberately partial: OAWM does not currently supply native
capacity registration/source journals or a registered source-accounting contract and
origin evidence. The complete OAWM qualification/source material remains in the
sidecar, with these exact unmapped obligations. No native VEK/CAIT acceptance is
claimed for this OAWM release, and no rate, causal origin, monetary-to-capability
conversion or reproduction estimate is invented.

The packaged companion manifest and [publication record](publication-0.2.0b0.md)
provide evidence for the actual tested version pairs. The
[research index](https://kadubon.github.io/github.io/collective-intelligence-index.ja.html)
is background; this task does not modify it or its relationship labels.
